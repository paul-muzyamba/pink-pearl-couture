
# Pink Pearl Couture ZM

Luxury fashion boutique landing page built with clean static frontend architecture.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```

pink-pearl-couture-structured/
│
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── main.js
│
└── README.md

```

## Deployment

This project is fully static and can be deployed directly to:

- GitHub Pages
- Vercel
- Cloudflare Pages
- Netlify
- Firebase Hosting
- Any Apache/Nginx server

## Deployment Instructions

### GitHub Pages

1. Push project to GitHub
2. Open repository settings
3. Go to Pages
4. Select branch
5. Deploy

### Vercel

1. Import GitHub repository
2. Framework preset: Other
3. Deploy

### Cloudflare Pages

1. Create new Pages project
2. Connect GitHub repository
3. Build command: leave empty
4. Output directory: `/`

## Notes

- No build tools required
- No framework dependency
- Fast loading and portable
- Easy to maintain and scale
- Separation of concerns implemented:
  - Structure → HTML
  - Styling → CSS
  - Functionality → JavaScript
